# Technical Welfare Fareed Kassar

**Our Village, Our Community, Our Responsibility.**

A digital community app for the residents of Fareed Kassar, District Chakwal, Punjab, Pakistan.

## What is in this repository
- `index.html` — a clickable design preview of the app (English + Urdu). It uses **demo data only**; nothing is saved to a database.

## Planned production stack
Next.js + TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Storage), installable as a PWA.

## Status
Design preview. The real app (with a database and real accounts) is being built in phases.

> Never commit passwords, API keys or `.env` files to this repository.
